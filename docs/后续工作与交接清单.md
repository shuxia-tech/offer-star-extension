## 阶段一：恢复环境与基础门禁（P0）

电脑维修后由代理执行：

1. 安装 Node.js 20+、Git、Chrome/Edge、Firefox。
2. 克隆仓库并执行 `npm ci`。
3. 执行 `npm run verify`，保存完整输出。
4. 运行 `npm run test:e2e:extension` 和 `npm run test:e2e:ai`。
5. 运行 `npm run test:firefox:runtime`。
6. 重新确认 `npm run test:firefox:fixture`。该命令在 Windows 上的 web-ext 调试端口参数曾需要修正，失败时要修脚本并记录日志，不得跳过。

完成标准：类型检查、全量单测、三浏览器构建、Manifest/契约/密钥检查和真实 Edge E2E 全部有本次环境输出。

## 阶段二：BOSS 直聘真实回归（P0）

需要用户完成：

1. 在 Firefox 中登录 BOSS 直聘。
2. 如果出现验证码、`_security_check` 或安全验证，用户手工完成。
3. 打开真实职位申请表，不要在验证码页面测试。
4. 用户点击悬浮球、扫描页面，再由用户确认后点击填写。

代理记录：脱敏 URL、识别字段数量、成功字段、失败字段、控制台中文日志和是否触发安全边界。禁止记录账号、密码、手机号、邮箱、身份证和完整简历。禁止自动提交职位。

完成标准：至少三个核心字段真实写入；非法值被拒绝；页面变化后旧结果失效；没有自动提交行为。若 BOSS 页面仍处于风控页，结果记录为“安全边界验证通过”，不能记为表单填写通过。
