# 2026-10-30 工作日志

## 修复：性别 select 与手机号区号下拉无法自动填充

用户反馈两张截图（性别下拉、手机号）简历有信息但填不上。

### 根因（两个 bug）

1. **`tupuPrimaryControl` 遗漏原生 `<select>`**（`src/content/dom-engine.ts`）
   `#candidateForm`（图普/Ant Design 表单）路径下，性别若是原生 `<select>`，最后 fallback 选择器只匹配 `textarea`/`input`，完全不含 `select`，导致该字段整组被跳过、扫描不到。

2. **`isPhoneCountryControl` 对原生 `<select>` 直接放行**
   手机号旁的国家区号若是原生 `<select>`（而非 `role=combobox` 的 div），会被误识别为 phone 字段，抢占了手机号键，导致真正的手机号 input 匹配失败、留空。

### 修复

- `tupuPrimaryControl` 在 radio 之后新增 `select:not([disabled])` 分支（保留 radio 优先级不变）。
- `isPhoneCountryControl` 对 `SELECT` 改为：手机号本身一定是输入框，若 select 的 label 推断为 phone，则视为区号下拉并过滤。

### 测试

- `tests/antd-form.test.ts`：新增「性别是原生 select」用例（含区号原生 select + 手机号 input）。
- `tests/async-native-select.test.ts`：新增「手机号旁原生 select 区号不抢占 phone」用例。
- typecheck、429 项单测、三浏览器构建均通过；radio/combobox/cascader 逻辑未受影响。

### 待办 / 风险

- 截图站点不确定（用户选「不确定/其他」），修复基于最可能 DOM 结构推演。建议用户在真实站点重新验证性别 select 与手机号能否填充。
